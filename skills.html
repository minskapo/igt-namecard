igt-namecard

명함 스킬

명함 내용 규칙, QR 추적링크, 추적링크 시트 기록, 강프린팅 발주 메시지 초안까지 담았습니다. 구성원 DB 시트를 기준으로 명함을 만듭니다.

이렇게 말하면 됩니다: “신규 입사자 ○○○ 명함 만들어줘”

명함 스킬 내려받기 (ZIP)
igt-email-signature

메일 서명 스킬

확정된 서명 디자인, 구성원별 UTM 규칙, 서명 이미지 올리기, 추적링크 시트 기록, GAM 일괄 적용과 개별 설치, 문제 해결 방법을 담았습니다.

이렇게 말하면 됩니다: “○○○ 메일 서명 만들어서 적용 준비해줘”

메일 서명 스킬 내려받기 (ZIP)
  1. 내려받기필요한 스킬의 ‘내려받기’를 눌러 ZIP 파일을 받습니다. 압축은 풀지 않습니다. 둘 다 설치해도 됩니다.
  2. 업로드Claude 스킬 설정(Customize › Skills)에서 + → Create skill → Upload a skill을 고르고 ZIP 파일을 올립니다.
  3. 켜기스킬 목록에 생긴 igt-namecard, igt-email-signature를 켭니다. 개인 요금제는 Settings › Capabilities에서 ‘Code execution and file creation’(파일 생성)이 켜져 있어야 합니다.
  4. 사용하기Claude에게 위 예시처럼 요청합니다. Google Sheets 커넥터를 연결해 두면 구성원 DB와 추적링크 시트 기록까지 대신 처리합니다.

Claude Code에서는 ZIP을 풀어 ~/.claude/skills/ 아래에 넣으면 됩니다. 스킬이 바뀌면 이곳 파일도 함께 갱신합니다.
