명함 만들기

엑셀 불러오기 → 구성원 선택 → 내용 확인 → 내려받기

1 연락처 엑셀 불러오기

파일은 이 브라우저 안에서만 읽힙니다. 서버로 전송되거나 저장되지 않습니다.

2 구성원 선택

엑셀을 불러오거나 ‘신규 입사자 직접 입력’을 눌러 주세요.

3 내용 확인·수정

목록에서 이름을 누르면 여기에서 내용을 고칠 수 있습니다.

부서·직급을 바꾸면 국문·영문 직함 줄이 자동으로 다시 채워집니다. 영문 이름은 로마자 표기법으로 자동 생성되므로 본인이 쓰는 표기를 확인해 주세요.

4 미리보기·내려받기

  • 대지 90×50mm
  • 도련 2mm
  • 단위 mm
  • 글자 아웃라인
  • 아트보드별 그룹

내용 수정은 연락처 엑셀이나 위 ③에서 한 뒤 다시 내려받으세요. 여러 명은 ZIP으로 받습니다.

추적링크 시트 가이드

명함 QR에는 사람마다 다른 추적 링크가 들어갑니다. 신규 발급자는 시트에 한 줄을 남겨 주세요.

추적링크 시트 열기
  1. 무엇인가요?이 링크가 누구 것인지 연구소 GA4 추적링크 시트(‘UTM코드 생성기’ 탭)에 한 줄씩 기록해 둡니다. 기존 구성원 23명은 이미 기록되어 있습니다.
  2. 신규 발급 시‘명함 만들기’ ②에서 신규 발급자를 체크하고 위 ‘시트에 붙여넣을 행 복사’를 누릅니다.
  3. 붙여넣기‘추적링크 시트 열기’ → ‘UTM코드 생성기’ 탭 맨 아래 빈 행의 A열을 클릭하고 붙여넣습니다(Cmd+V / Ctrl+V). 생성일·작성자(명함생성기 자동생성)·메모·랜딩·캠페인·소스·매체·콘텐츠·UTM 링크·단축링크가 A~L열에 채워집니다.
  4. 성과 보기GA4에서 세션 소스/매체가 bizcard / qrcode인 유입이 명함 QR로 들어온 방문입니다. 캠페인은 business_card, 콘텐츠(utm_content)는 구성원 이메일 아이디라 사람별로 나눠 볼 수 있습니다.

시트를 붙여넣지 않아도 QR과 GA4 추적은 작동합니다. 시트는 링크 관리용 기록이며, 연구소 계정으로 공유된 사람만 열 수 있습니다.

Claude 명함 스킬 설치

Claude에게 “○○○ 명함 만들어줘”라고 말하면 이 페이지의 흐름대로 처리합니다.
igt-namecard

명함 내용 규칙, QR 추적링크, 추적링크 시트 기록, 강프린팅 발주 메시지 초안까지 담은 Claude 스킬입니다. 연구소 구성원 누구나 설치해 쓸 수 있습니다.

스킬 파일 내려받기 (ZIP) Claude 스킬 설정 열기
  1. 내려받기위 ‘스킬 파일 내려받기’를 눌러 igt-namecard.zip을 받습니다. 압축은 풀지 않습니다.
  2. 업로드‘Claude 스킬 설정 열기’(Customize › Skills)에서 + → Create skill → Upload a skill을 고르고 ZIP 파일을 올립니다.
  3. 켜기스킬 목록에 생긴 igt-namecard를 켭니다. 개인 요금제는 Settings › Capabilities에서 ‘Code execution and file creation’(파일 생성)이 켜져 있어야 합니다.
  4. 사용하기Claude에게 “신규 입사자 ○○○ 명함 만들어줘”처럼 요청합니다. Google Sheets 커넥터를 연결해 두면 추적링크 시트 기록까지 대신 처리합니다.

Claude Code에서는 ZIP을 풀어 ~/.claude/skills/igt-namecard/에 넣으면 됩니다. 스킬이 바뀌면 이곳 파일도 함께 갱신합니다.
