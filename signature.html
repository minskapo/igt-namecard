Gmail 일괄 적용 파일이 바로 만들어집니다.

기본관리자가 한꺼번에 적용

모든 구성원의 Gmail 웹·앱 서명은 관리자가 GAM으로 한 번에 넣습니다. 구성원은 따로 할 일이 없습니다.

관리자 일괄 적용
개별직접 넣어야 하는 경우

Outlook·Apple Mail 같은 다른 메일 프로그램을 쓰거나, 영문 서명을 하나 더 두고 싶을 때는 아래 도구에서 복사해 직접 붙여 넣습니다.

개별 설치
신규새 구성원이 들어오면

DB 시트에 한 줄을 넣고, 이 페이지에서 배포 파일을 받아 저장소에 올린 뒤 관리자가 그 사람만 적용합니다.

DB 시트 열기 DB를 .xlsx로 받기

DB는 이 브라우저 안에서만 읽히고 저장되지 않습니다. DB 시트를 공유받은 연구소 계정만 불러올 수 있습니다.

2 구성원 선택

DB를 불러오거나 ‘직접 입력’을 눌러 주세요.

3 내용 확인·수정

목록에서 이름을 누르면 여기에서 내용을 고칠 수 있습니다.

여기서 고친 내용은 DB 시트에 저장되지 않습니다. 계속 쓸 내용은 DB 시트를 고친 뒤 다시 불러오세요.

4 미리보기·복사·내려받기

구성원을 고르면 서명이 여기에 보입니다.

    선택한 사람의 서명 이미지(저장소에 올릴 파일), GAM 일괄 적용 파일, 사람별 HTML이 함께 들어 있습니다.

    관리자 일괄 적용 (GAM)

    GAM 안내서

    Google Workspace 관리자가 명령 한 줄로 모든 구성원의 Gmail 서명을 바꿉니다. 처음 한 번 GAM을 설치하고 권한을 연결해 두면, 그 뒤로는 3~5단계만 반복합니다.

    1. GAM 설치관리자 PC에 GAM을 설치합니다. 맥·리눅스는 터미널에서 bash <(curl -s -S -L https://git.io/gam-install), 윈도우는 GAM 안내서의 설치 파일을 씁니다.
    2. 권한 연결설치 안내에 따라 gam create project → gam oauth create → gam user 관리자@igt.or.kr check serviceaccount를 차례로 실행합니다. 마지막 단계에서 나오는 주소로 관리 콘솔의 ‘도메인 전체 위임’을 승인하면, 구성원 서명을 바꿀 권한(Gmail settings)이 생깁니다.
    3. 배포 파일 받기위 ‘서명 만들기’에서 DB를 불러오고 전체 선택 → 배포 파일 ZIP을 받아 압축을 풉니다.
    4. 이미지 올리기ZIP 안 저장소에_올릴_파일/assets 폴더를 명함생성기 저장소(minskapo/igt-namecard) 맨 위에 그대로 덮어쓰고 커밋·push 합니다. 1~2분 뒤 ZIP 안 이미지_주소_확인.txt의 주소를 하나 열어 이미지가 보이면 준비가 끝난 것입니다.
    5. 일괄 적용압축을 푼 폴더에서 gam csv gam/signatures.csv gam user ~email signature file ~file html을 실행합니다. 한 사람만 바꿀 때는 gam user minski@igt.or.kr signature file gam/html/minski.html html처럼 씁니다.
    6. 확인gam user minski@igt.or.kr show signature로 들어간 서명을 확인하고, 본인 Gmail에서 새 메일을 열어 서명이 붙는지 봅니다.

    추적 링크: 서명 버튼에는 연구소 GA4 추적링크 시트 규칙대로 utm_source=signature · utm_medium=email · utm_campaign=email_signature가 붙고, utm_content에는 구성원 이메일 아이디, utm_term에는 누른 버튼(donate·newsletter·homepage·website·card)이 들어갑니다. GA4에서 세션 소스/매체 signature / email로 보면 메일 서명으로 들어온 방문이고, 콘텐츠·검색어로 사람별·버튼별로 나눠 볼 수 있습니다. LinkedIn 버튼은 외부 사이트라 추적 링크를 붙이지 않습니다.

    일괄 적용은 사람마다 서명 하나(DB의 ‘서명 언어’)만 넣습니다. 영문 서명을 함께 쓰려는 사람은 아래 개별 설치로 하나 더 추가합니다. 적용하면 기존 서명은 바뀌므로, 미리 공지해 주세요.

    DB 바로 불러오기 설정 (처음 한 번)

    ‘Google 계정으로 DB 불러오기’ 버튼을 쓰려면 Google Cloud에서 로그인용 클라이언트 ID를 하나 만들어야 합니다. GAM을 설치할 때 만든 Cloud 프로젝트를 그대로 쓰면 됩니다.

    1. API 켜기Google Cloud 콘솔에서 프로젝트를 고르고 Google Sheets API를 ‘사용’으로 바꿉니다.
    2. 동의 화면API 및 서비스 › OAuth 동의 화면(Google 인증 플랫폼)에서 사용자 유형을 내부로 정합니다. 앱 이름은 ‘녹색전환연구소 디자인 산출물 통합도구’로 적습니다. 내부 앱은 연구소 계정만 쓸 수 있고 별도 심사가 없습니다.
    3. 클라이언트 ID사용자 인증 정보 › 사용자 인증 정보 만들기 › OAuth 클라이언트 ID › 유형 ‘웹 애플리케이션’을 고르고, 승인된 JavaScript 원본에 https://minskapo.github.io를 넣고 만듭니다.
    4. 연결만들어진 클라이언트 ID(…apps.googleusercontent.com)를 저장소 js/db-load.js의 clientId에 넣고 push 하거나, 김민석에게 보내 주세요. 클라이언트 ID는 공개되어도 괜찮은 값입니다.

    불러오기는 로그인한 사람의 권한으로 시트를 읽기만 합니다. DB 시트를 공유받지 않은 계정은 불러올 수 없고, 읽은 내용은 브라우저 밖으로 나가지 않습니다.

    개별 설치

    직접 서명을 넣어야 할 때

    ‘서명 만들기’에서 본인을 고른 뒤 서명 복사를 누르고, 쓰는 메일 프로그램의 서명 칸에 붙여 넣습니다.

    Gmail 웹 (영문 서명 추가)설정(톱니바퀴) › 모든 설정 보기 › 기본설정 › 서명 › 새로 만들기 → 붙여넣기. 아래 ‘서명 기본값’에서 새 메일·답장에 쓸 서명을 고르고 맨 아래 변경사항 저장을 누릅니다.
    Gmail 앱 (휴대폰)최신 Gmail 앱은 웹 서명을 가져와 씁니다. 앱 설정 › 계정 › 서명에서 웹 서명이 골라져 있는지 확인하고, ‘모바일 서명’(글자만 쓰는 서명)이 켜져 있으면 꺼 둡니다. 앱이 오래된 버전이면 업데이트해 주세요.
    Outlook (Windows·Mac·웹)설정 › 메일 › 서명(새 Outlook은 계정 › 서명) › 새 서명 → 붙여넣기 → 새 메일·회신 기본값 지정. 이미지가 안 보이면 ‘HTML 내려받기’ 파일을 브라우저로 열어 서명 부분을 복사해 다시 붙입니다.
    Apple Mail (Mac)설정 › 서명 › 계정 선택 › + → ‘항상 기본 메시지 서체와 일치’를 끄고 붙여넣기. 붙인 직후 이미지가 회색으로 보여도 보내는 메일에는 정상으로 들어갑니다.
    iPhone 기본 메일설정 › 앱 › Mail › 서명에 붙여 넣으면 이미지가 빠지거나 깨질 수 있습니다. 이때는 글자 서명 복사로 글자만 넣어 주세요.
    Thunderbird 등 기타‘HTML 내려받기’로 받은 파일을 서명 파일로 지정하거나(HTML 사용 켜기), 내용을 서명 칸에 붙여 넣습니다.

    서명 복사는 저장소에 이미지가 올라간 사람만 정상 작동합니다. 미리보기 아래에 ‘이미지 준비됨’이 보이는지 먼저 확인하세요.

    신규 구성원·정보 변경

    1. DB에 적기DB 시트 ‘구성원’ 탭 맨 아래에 한 줄을 넣습니다. 이메일 아이디·이름·부서·직급·핸드폰·이메일만 채우면 되고, 영문 이름과 직함은 비워 두어도 자동으로 채워집니다. 퇴사자는 ‘상태’를 퇴사로 바꿉니다.
    2. 배포 파일 받기DB를 다시 받아 불러온 뒤 그 사람만 골라 배포 파일 ZIP을 받습니다. 서명 코드가 비어 있던 사람은 도구가 코드를 새로 만들고, ZIP 안 서명코드_DB기록.csv에 적어 줍니다. 이 코드를 DB ‘서명 코드’ 칸에 꼭 옮겨 적어 주세요.
    3. 추적링크 기록같은 사람을 고른 채 추적링크 시트 행 복사를 누르고, GA4 추적링크 시트 ‘UTM코드 생성기’ 탭 맨 아래 빈 행의 A열에 붙여 넣습니다. 사람마다 버튼별로 5줄이 들어갑니다. 명함 QR 기록과 같은 방식입니다.
    4. 올리고 적용위 관리자 4~5단계처럼 이미지를 저장소에 올리고, 관리자가 그 사람만 gam user …로 적용합니다. 관리자가 없을 때는 본인이 개별 설치로 넣어도 됩니다.
    5. 정보가 바뀌면직급·전화가 바뀌어도 서명 코드는 그대로 둡니다. 같은 과정으로 이미지를 다시 올리고 다시 적용하면, 이미지 주소의 버전 값이 바뀌어 새 서명이 바로 보입니다.

    문제 해결

    서명 이미지가 엑스(X)나 빈칸으로 보여요

    이미지가 저장소에 아직 안 올라갔거나 push 직후일 수 있습니다. ‘서명 만들기’ 미리보기 아래 상태를 확인하고, ‘이미지 준비 안 됨’이면 관리자 4단계를 다시 해 주세요. 받는 사람 메일 프로그램이 외부 이미지를 막아 둔 경우에는 ‘이미지 표시’를 눌러야 보입니다.

    바꾼 내용이 서명에 반영되지 않아요

    이미지만 다시 올리고 서명을 다시 적용하지 않으면 예전 주소가 남아 있습니다. 배포 파일을 새로 받아 다시 적용해 주세요. Gmail은 이미지를 한동안 저장해 두므로, 주소가 같은 상태로는 바로 바뀌지 않을 수 있습니다.

    서명이 두 번 붙거나 휴대폰에서 다른 서명이 붙어요

    Gmail 앱의 ‘모바일 서명’, Outlook·Apple Mail의 서명이 함께 켜져 있는지 확인하세요. Gmail로 보내는 메일에는 Gmail 서명 하나만 켜 두면 됩니다.

    다크모드에서 서명이 하얀 상자로 보여요

    의도된 모습입니다. 서명 전체를 이미지로 만들어 다크모드에서도 원래 색이 유지되도록 했습니다.

    버튼을 누르면 google.com을 거쳐 열려요

    Gmail이 받은 메일의 링크를 안전 확인 주소로 감싸는 기능입니다. 실제 이동하는 주소는 그대로이며, 서명에서 뺄 수 없습니다.

    이름이나 직함이 잘리거나 작게 나와요

    서명 폭(600px)을 넘는 글자는 도구가 조금씩 줄여 맞추고, 그래도 넘으면 미리보기 아래에 경고를 띄웁니다. DB의 영문 직함 줄을 짧게 고친 뒤 다시 만들어 주세요.

    GAM에서 권한 오류가 나요

    gam user 관리자@igt.or.kr check serviceaccount를 다시 실행해 빠진 권한을 확인하고, 안내되는 주소에서 도메인 전체 위임을 승인합니다. 서명 변경에는 Gmail settings(basic·sharing) 권한이 필요합니다.

    그래도 안 되면 기후시민팀 김민석(minski@igt.or.kr)에게 화면을 캡처해 보내 주세요.
